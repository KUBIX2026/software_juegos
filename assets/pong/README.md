# assets/pong

Diseños del equipo de arte para Pong: menús, pantalla de pausa y pantalla de partida de referencia.

El juego **no** usa esta carpeta. Sus sprites, con los que se genera `pong/include/assets.h`, están en [`pong/assets`](../../pong/assets); ahí los dígitos y las paletas son distintos y hay además cursor y rótulos.
